# ─────────────────────────────────────────────────────────────────────
# LAMA — LOCAL DEV requirements (macOS / Apple Silicon, Python 3.14)
#
# `requirements.txt` remains the SOURCE OF TRUTH for the container image
# (python:3.11-slim-bookworm). Do not use this file for the Docker build.
#
# Why this file exists
# --------------------
# Two reasons, and as of 2026-09 only the second one still holds.
#
#  1. (HISTORICAL) `requirements.txt` used to be a `pip freeze` taken on a
#     Linux CUDA machine, carrying 19 `nvidia-*` / `cuda-*` / `triton`
#     pins with no macOS wheels, so it could not install on a Mac at all.
#     That freeze has since been pruned to direct dependencies only and no
#     longer names a single CUDA package.
#
#  2. (CURRENT) The container targets Python 3.11; this machine runs 3.14.
#     Four pins that resolve fine on 3.11 have no cp314 wheel, and the
#     local HuggingFace/torch stack is skipped entirely to keep the dev
#     venv small. Those deltas are what this file still exists to carry.
#
# How it was derived (not guesswork)
# ----------------------------------
# Every .py file under backend/ was AST-parsed for its real import graph
# (160 files, 0 parse failures). That yields 31 third-party modules. Note
# that grepping for `import X` gives the WRONG answer here: several files
# (integrations/platform_catalog.py, datamodel/migration_generator.py)
# embed `import boto3` / `import psycopg2` inside string templates that
# are emitted into GENERATED user projects — they are not LAMA runtime
# dependencies.
#
# Versions match `requirements.txt` exactly wherever Python 3.14 allows,
# so local behaviour tracks the container. Only three pins are relaxed,
# each annotated below with the reason.
#
# Usage
# -----
#   cd backend
#   python3 -m venv venv
#   ./venv/bin/python -m pip install -U pip
#   ./venv/bin/python -m pip install -r requirements-dev-macos.txt
#   ./venv/bin/uvicorn server:app --reload --port 8000
#
# Verified: `import server` succeeds and exposes all 283 /api routes.
# ─────────────────────────────────────────────────────────────────────
